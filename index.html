السؤال الأول

Setter & Getter

أكمل الكود التالي بحيث يعمل البرنامج بشكل صحيح.

المطلوب:

  • أكمل الـ Setter والـ Getter لكل Attribute (name و age و grade).
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int age;
    double grade;

public:

};

int main() {

    Student s;

    s.setName("Ahmed");
    s.setAge(20);
    s.setGrade(90);

    cout << s.getName() << endl;
    cout << s.getAge() << endl;
    cout << s.getGrade() << endl;

    return 0;
}

السؤال الثاني

Inheritance & Method Overriding

أكمل الكود التالي بحيث تقوم BMW بالوراثة من Car وتعمل Override للـ start().

المطلوب:

  • أكمل الـ Inheritance.
  • أكمل تعريف الـ start().
  • يجب أن يكون الناتج كما في المربع أدناه.

الناتج المطلوب (Output)

BMW Started
#include <iostream>
using namespace std;

class Car {
public:
    virtual void start() {
        cout << "Car Started" << endl;
    }
};

int main() {

    BMW car;

    car.start();

    return 0;
}
